# Anni Fitness

Multi-page website for Anni Fitness, a strength and conditioning club. Dark athletic layout, poster type, and interactive 3D pieces: a barbell you can load, a three-ring mark, and a kettlebell you can swing.

## Pages

- Home
- About
- Programs
- Trainers
- Membership
- Schedule
- Contact

## Preview

The 3D scenes load Three.js from a CDN, so open the site over HTTP rather than as a local file:

```bash
python3 -m http.server 4173
```

Then visit `http://localhost:4173`.

## Before you publish

Address, hours, prices, class times, and coach names are starter content. Replace them, including `hello@annifitness.example`. The contact form stays in the browser until you connect it to an inbox.

This repository’s README is what GitHub shows on the profile. The site itself is the HTML pages. Project Pages, if you turn them on, publish from this repo.
